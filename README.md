# LevelUP Math Arena

Prototype game matematika 2D multiplayer berbasis browser untuk sesi private dengan satu host/guru dan dua pemain dari jenjang berbeda.

## MVP

Empat mode permainan dalam satu sesi:

1. Tug of War
2. Math Racing
3. Boss Battle
4. Bomb Defuse

Stack utama: Next.js, TypeScript, Phaser, Supabase Realtime/Postgres, dan Vercel.
